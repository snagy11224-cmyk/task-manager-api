# Task Manager API

RESTful task management API built with Node.js and Express.js, focused on authentication, authorization, CRUD operations, validation, and clean backend structure.

## Features

- User authentication
- User authorization
- Task CRUD operations
- Request validation
- Error handling
- Middleware-based request processing
- Modular backend architecture
- RESTful API design

## Tech Stack

- Node.js
- Express.js
- MongoDB
- JavaScript
- Git & GitHub

## What I Built

This project focuses on building a backend API for managing user tasks with authentication and authorization.  
It demonstrates core backend development skills such as REST API design, routing, middleware, validation, database integration, and structured error handling.
